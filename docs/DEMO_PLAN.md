# ClearTask — demo plan

## 90-second walkthrough
1. **Problem (10 sec):** identify the specific user and pain point.
2. **Start (10 sec):** open the app and explain the main action.
3. **Core workflow (45 sec):** complete one realistic example from input to useful result.
4. **Trust and limitations (15 sec):** show sample-data labels, privacy choices, and what the app does not claim to do.
5. **Impact (10 sec):** explain one measurable outcome the prototype could support.

## Recording checklist
- Use fictional/demo information only.
- Start from a clean state and rehearse the exact click path.
- Hide API keys, personal accounts, and private notifications.
- Keep narration aligned with working features; do not describe planned features as finished.
- Capture the full screen at readable zoom and include captions or a transcript when practical.
