# ClearTask demo script (baseline prototype)

Target duration: 90–120 seconds.

1. Introduce the user: a student who knows what an assignment is about but is unsure how to start.
2. Enter a realistic task description and select School assignment.
3. Set available work time and an optional date.
4. Build the starter plan.
5. Edit one suggested step to show that the student remains in control.
6. Mark two steps complete and show the progress indicator update.
7. Export the plan as a Markdown checklist.
8. Explain the limitation: without an API key, the app uses deterministic templates. With a configured provider, an optional AI route proposes editable steps. Do not claim live AI works until it has been tested with a valid key. The tool does not complete the assignment.

Do not present the template planner as AI-generated. For the Global AI Builder's Challenge, record the actual event-period improvements separately and update this demo after those changes exist.
