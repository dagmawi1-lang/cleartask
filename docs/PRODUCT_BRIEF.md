# Product brief — Global AI Builder’s Challenge — ClearTask

## Working concept
ClearTask: an AI-assisted task explainer for students that turns a confusing assignment or multi-step everyday task into a clear, editable sequence with estimated effort, prerequisite questions, and a progress checklist. It should ask clarifying questions and avoid doing graded work on the student’s behalf.

## User problem
Make the problem concrete and identify one primary user. Avoid broad claims that cannot be demonstrated.

## MVP experience
1. Clear landing screen explaining the problem and intended user.
2. One complete core workflow that works without external credentials.
3. Sample/demo data that is clearly labeled.
4. Helpful empty, loading, and error states.
5. Accessible keyboard navigation and responsive layout.

## Stretch goals
- Optional AI feature with transparent disclosure and a non-AI fallback.
- Export/shareable result.
- Usage analytics that do not collect personal information.

## Success criteria
- A judge can understand the value in under 30 seconds.
- The core workflow can be demonstrated end-to-end in under 2 minutes.
- Every visible control works or is clearly marked as a future feature.
