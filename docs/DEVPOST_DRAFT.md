# Devpost draft — ClearTask

## Short description
ClearTask helps students turn a confusing assignment or multi-step task into an editable plan with small actions, rough time estimates, and a progress checklist.

## Inspiration
A student can understand the topic but still feel stuck because the work seems too large or the first step is unclear. ClearTask focuses on planning and momentum rather than producing the student's work.

## What it does
The baseline lets a student describe a task, choose school or everyday mode, set available time, edit suggested steps, track progress, and export a Markdown checklist.

## How we built it
React, Vite, JavaScript, CSS, local storage, Lucide React, and Node's built-in test runner. The baseline uses deterministic templates and includes an optional server-side AI route. The live provider path must be tested and accurately disclosed before the final submission.
