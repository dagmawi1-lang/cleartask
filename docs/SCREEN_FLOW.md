# ClearTask — screen flow

1. Student enters a task description in their own words. 2. App asks one or two clarifying questions about the expected outcome and constraints. 3. App produces a draft sequence of small steps, prerequisites, and rough effort estimates. 4. Student edits or rejects any step. 5. Student checks off progress and exports the plan. 6. A clear integrity reminder says the tool organizes work but does not complete graded assignments.
